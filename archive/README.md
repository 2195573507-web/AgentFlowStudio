# Archive

This folder stores historical project materials that are useful for audit and context, but should not stay in the active project surface.

## Layout

- `2026-05/root-progress/` - previous root-level planning and rebuild progress notes.
- `2026-05/handoff-history/` - older handoff progress snapshots and validation summaries.
- `2026-05/reports/` - historical human simulation and validation reports.
- `2026-05/parallel-agents/` - archived parallel-agent task files, logs, summaries, and review notes.

## Active Files Kept Outside Archive

- `PROJECT_PROGRESS.md` remains at the repository root because release status reads it.
- `handoff/TEST_REPORT.md` remains active because release status and smoke checks read it.
- Core handoff files checked by `scripts/verify-build.js` and `scripts/smoke-test.js` remain under `handoff/`.
